# TextVision — 계기 태그 추출기

DCS/SCADA/HMI 화면이나 P&ID를 캡처한 이미지에서 계기 태그와 각 태그에 표시된 레벨(값)을 찾아 표로 정리하고, 엑셀(.xlsx) 파일로 내보내는 웹페이지입니다.

기본으로 찾는 태그 접두어는 `AV, PT, PIT, MG, LT, TT, FT, FC, LIT, MP`이며, 화면에서 바꿀 수 있습니다.

## 사용 방법

1. `index.html`을 브라우저로 엽니다. GitHub Pages로 배포했다면 그 주소로 접속합니다.
2. **인식 엔진**을 고릅니다.
   - **Claude AI 비전 (권장)**: 가장 정확합니다. 작은 글씨, 어두운 HMI 화면, 복잡한 배치에서도 태그와 값을 잘 짝지어 읽습니다. [Anthropic API 키](https://console.anthropic.com/)가 필요하며 사용량만큼 요금이 나옵니다.
   - **Tesseract OCR**: 무료이고 이미지가 외부로 전송되지 않지만 정확도가 낮습니다. 처음 실행할 때 언어 데이터(약 수 MB)를 내려받습니다.
3. 캡처 이미지를 끌어다 놓거나, 클릭해서 선택하거나, 캡처 직후 페이지에서 **Ctrl+V**(맥은 ⌘+V)로 붙여넣습니다. 여러 장도 됩니다.
4. **태그 추출하기**를 누릅니다. 아직 추출하지 않은 이미지만 처리하므로, 이미지를 더 추가하고 다시 눌러도 앞서 고친 내용은 그대로 남습니다. 진행 중에는 **중지**로 멈출 수 있습니다.
5. 결과 표에서 접두어 버튼으로 걸러 보거나, 칸을 클릭해 잘못 읽힌 글자를 고칩니다.
6. **엑셀로 내보내기**를 누르면 다음 시트가 담긴 파일이 저장됩니다.
   - `요약`: 접두어별 태그 수와 "태그 = 값" 목록
   - `전체 목록`: 모든 태그 (구분, 태그, 레벨(값), 단위, 상태/알람, 설명, 신뢰도, 원본 이미지)
   - 접두어별 시트 (`AV`, `PT`, ...): 해당 접두어 태그만

## Claude 모델 선택

| 모델 | 특징 |
|---|---|
| Claude Opus 5.5 (기본값) | 정확도와 비용의 균형이 가장 좋습니다 |
| Claude Fable 5.1 | 가장 뛰어난 모델이며, 비용은 Opus 5.5의 약 2.5배입니다 |
| Claude Sonnet 5.5 | 더 빠르고 저렴합니다 |

**추론 강도**를 높이면 더 꼼꼼하게 읽지만 느려지고 비용이 늘어납니다. 기본값은 "높음"입니다.

큰 캡처(예: 4K 화면)는 글자가 뭉개지지 않도록 전체 축소본과 원본 해상도 타일로 나눠 한 번에 보냅니다.

## 개인정보와 API 키

- Claude 엔진을 쓰면 이미지가 분석을 위해 Anthropic API로 전송됩니다. 외부로 보내면 안 되는 화면이라면 Tesseract 엔진을 쓰세요.
- API 키는 브라우저에서 `api.anthropic.com`으로만 직접 전송됩니다. 별도 서버를 거치지 않습니다.
- "이 브라우저에 키 기억하기"를 켜면 키가 브라우저 저장소(localStorage)에 남습니다. 공용 PC에서는 끄세요.
- 여러 사람이 함께 쓸 사이트라면 각자 자기 API 키를 넣어 쓰는 방식입니다. 키를 페이지 코드에 넣어 두지 마세요.

## 웹사이트로 배포하기 (GitHub Pages)

1. 이 브랜치를 `main`에 병합합니다.
2. 저장소의 **Settings → Pages**에서 **Source**를 `Deploy from a branch`, 브랜치를 `main` / `(root)`로 지정하고 저장합니다.
3. 1~2분 뒤 `https://<사용자이름>.github.io/textvision1/`로 접속할 수 있습니다.

> 비공개(private) 저장소에서 GitHub Pages를 쓰려면 GitHub Pro 이상의 요금제가 필요합니다. 무료 계정이라면 저장소를 공개로 바꿔야 합니다. 저장소를 공개해도 API 키는 코드에 없으므로 노출되지 않습니다.

## 파일 구성

- `index.html`: 페이지 전체 (화면, 인식, 결과 표, 엑셀 내보내기)
- `vendor/anthropic-sdk.min.js`: 공식 Anthropic JavaScript SDK를 브라우저용으로 묶은 파일. 다시 만드는 방법은 [`vendor/README.md`](vendor/README.md)에 있습니다.
- Tesseract.js 7.0.0과 ExcelJS 4.4.0은 필요할 때 jsDelivr CDN에서 불러옵니다(무결성 해시 SRI로 검증).
